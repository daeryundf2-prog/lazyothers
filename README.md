# LazyOthers

Google Antigravity용 독립 MCP 도구 모음 플러그인입니다.

## 📦 포함된 도구 (Bundled MCP Tools)
1. **`context7`**: 공식 라이브러리 및 최신 프레임워크 문서 조회
2. **`grep_app`**: GitHub 오픈소스 전역 코드 검색
3. **`kordoc`**: 한국 공문서(HWP/PDF/DOCX) 파싱, 서식 입력, 직인 날인, 비식별화
4. **`xds`**: 엔지니어링 데이터 및 문서 검색

## 🚀 다른 컴퓨터에서 설치 방법 (Setup on New Machine)
```bash
# 1. 플러그인 클론
cd ~/.gemini/config/plugins
git clone https://github.com/daeryundf2-prog/lazyothers.git lazyothers

# 2. Antigravity MCP 디렉터리로 자동 동기화
cd lazyothers
npm run setup
```
